# Telegram через Wazzup API: BAD_CONTACT на ЛЮБОЙ чат

**Аккаунт:** канал `1c2ef310-836a-4c16-8f1e-387579ae8146`, transport `tgapi`,
`plainId` 79771501819, state `active`.

## Симптом

`POST /v3/message` возвращает **HTTP 201** с `messageId`, то есть запрос принят.
Через ~2 секунды приходит webhook-эхо:

```json
{
  "messageId": "d348e584-4425-4688-8942-8daa428c82d7",
  "chatType": "telegram",
  "chatId": "79771501819",
  "type": "text",
  "isEcho": true,
  "status": "error",
  "authorName": "Admin",
  "error": {
    "error": "BAD_CONTACT",
    "description": "Recipient with this chatId does not exist"
  }
}
```

Это происходит **даже при отправке самому себе** (79771501819 → 79771501819),
то есть чат существует по определению.

| Гипотеза | Проверка | Результат |

| Номер не в Telegram | отправка самому себе | `BAD_CONTACT` |
| Спам-бан аккаунта | в аккаунте есть история: 160 read, 40 answered (27–29 авг, 1–24 сен) | бан не подтверждается, API не работает даже «самому себе» |

Из UI Wazzup сообщение уходит нормально. Через API — нет.
