# Одобренные в Meta тексты — ЭТАЛОН СМЫСЛА.

Этот файл — единственный источник правды о том, ЧТО мы обещаем человеку.
Правило: текст для Telegram/MAX должен быть максимально близок ПО СУТИ к тексту
отсюда. Отклоняться можно только в словах, которые не меняют предложение
(приветствие, синоним термина, форма приглашения связаться).

Чего делать НЕЛЬЗЯ (это и была причина жалоб):
- терять процент — «получать стабильно годовых» без цифры это не оффер;
- разбавлять «25%» до «до 25%» или «около 25%» — это разные обещания;
- подменять запрос на связь чем-то вроде «Что думаете?» — это не просьба связаться;
- мешать «ты» и «вы» внутри одного предложения.

# Правки относительно дословного текста из Meta, сделанные осознанно:
# - «Здравствуй ,» -> «Здравствуйте,» и «с тобой» -> «с вами»: в оригинале
#   «ты» мешалось с «вы» внутри одной категории, из-за этого сообщение читалось
#   как собранное из двух разных текстов. Регистр выбран единым «вы».
# - Добавлено {имя}: без него все сообщения категории были побайтово одинаковыми,
#   что для Telegram/MAX выглядит как явная массовая рассылка.
